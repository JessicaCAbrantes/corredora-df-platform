# Footer

Componente de rodapé da aplicação.

## Objetivo

Exibir links institucionais, redes sociais, informações legais e branding da Plataforma Corredora DF.

## Exemplos de uso

```tsx
// app/layout.tsx
<Footer />
```

## Boas práticas

- Conteúdo estático ou configurável via props/constants.
- Links para termos de uso, política de privacidade e contato.
- Manter leve — sem lógica de negócio.
- Consistência visual com o Navbar.
