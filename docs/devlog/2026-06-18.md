## Decisões

- **pnpm 11** como gerenciador de pacotes.
- **Turborepo** para orquestração do monorepo.
- **Feature-Based Design** no frontend — domínios auto-contidos.
- **API-first** — contratos documentados antes da implementação NestJS.
- **Butterfly UI** como design system em `packages/ui` — compartilhado no monorepo.
- **Documentação por domínio** — engineering, api, product, ux, adr separados.
- **REST + `/api/v1`** com envelope de resposta único.
- Next.js para frontend, NestJS + PostgreSQL + Prisma planejados para backend.
